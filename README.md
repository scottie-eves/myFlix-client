# myFlix-Client

## Project Overview

Flix-Vault is a client-side front-end web application that allows users to log in and access a wide range of movie information. Each movie entry includes details such as the title, description, director, genre, and image providing users with a comprehensive movie database.

## Features

- User authentication and account management
- Movie search functionality
- Favorites management (add and remove favorite movies)
- Responsive design for optimal viewing on various devices

## Technologies Used

- React: A JavaScript library for building user interfaces
- React-Bootstrap: Bootstrap components for React
- Parcel: A web application bundler
- Axios: Promise-based HTTP client for making API requests
